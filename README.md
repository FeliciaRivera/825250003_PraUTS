## Fitur

- Header 2 kolom (logo dan judul)
- Menu navigasi satu baris; di layar kecil berubah menjadi ikon 3 garis
- Konten 2 kolom: kiri 6 kartu artikel (grid 3 kolom), kanan 3 kotak sidebar
- Footer 2 bagian: atas 3 kolom, bawah copyright
- Menu Contact membuka popup profil mahasiswa (memakai `:target`, tanpa JavaScript)
- Menu Blog membuka `blog.html`; Home dan "Kembali ke Halaman Utama" kembali ke `index.html`
- Link situs eksternal (Lorem Ipsum Official, Google Search, Wikipedia) dibuka di tab baru
- Galeri foto dengan efek opacity dan transisi saat hover
- Responsif untuk desktop, tablet (maks 900px), dan HP (maks 600px)

## Teknologi

- HTML5
- CSS3: Grid, Flexbox, variabel CSS, transition, media query
